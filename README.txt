ACDmixArt — site pentru GitHub Pages

1. Creează un cont GitHub (dacă nu ai deja).
2. Creează un repository numit exact: acdmixart.github.io
3. Încarcă index.html, style.css și script.js.
4. În repository: Settings → Pages → Deploy from a branch → main → /root.
5. Site-ul va fi disponibil la https://acdmixart.github.io/

În index.html înlocuiește:
- linkurile Facebook/WhatsApp cu linkurile tale exacte;
- fotografia demonstrativă din hero cu fotografia ta din atelier.

Poți schimba textele, produsele și culorile direct în index.html și style.css.
